Privacy Policy

Quis Primus Uploader · Last updated: October 7, 2026

What this application is

Quis Primus Uploader is a private tool used by the owner of the Quis Primus YouTube channel to upload the channel's own videos. It is not offered to the public and has a single user: the channel owner.

YouTube API Services

This application uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data we access

With the channel owner's authorization, the application uploads videos and their titles, descriptions and tags to the owner's YouTube channel, and reads basic information about that channel and its videos. It does not access data of any other YouTube user.

How data is stored and shared

The only stored credential is the channel owner's OAuth refresh token, kept as an encrypted secret in the owner's private build environment. No personal data is collected, sold or shared with third parties. Video metadata created by the application is published on YouTube by design.

Revoking access

Access can be revoked at any time on the Google security settings page. Revoking access stops all uploads immediately.
